            Conexão com o Jira

            Gere um token em id.atlassian.com → Segurança → Criar e gerenciar tokens de API e preencha os campos abaixo. O passo a passo completo está em docs/CONFIGURACAO-JIRA.md.

              Adicionar planilhas do Jira

              Arraste os arquivos .xlsx ou .csv exportados do Jira, ou clique para escolher. As atividades são identificadas pela Chave da item: reenviar uma planilha com itens repetidos atualiza os registros em vez de duplicar.
